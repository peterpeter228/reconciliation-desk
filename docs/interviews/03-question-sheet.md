# 访谈 03：事务所负责人

状态：PREPARED_NOT_RUN。角色假设：付款人与质量责任人；有团队交接经验。无名单、未联系。

## 问题单（先问真实过去行为）

1. 请讲最近一个历史清理项目，为什么客户愿意付钱，交付物是什么？
2. 哪部分人工成本最难估计？返工通常因数据缺失、映射还是会计判断？
3. 团队如何留存来源、复核与审批？新的证据包要经过谁认可？
4. 你会如何比较连接式工具、本地文件工具和继续人工？什么情况直接不用？
5. 采购是否由你决定？试用与正式采购需要哪些条件？不要提供预算文件。

## 演示之后才问

6. 请用自己的话解释三条证据边。哪一项结论你仍不会信？
7. 你会保留哪个交付物，丢掉哪个？为什么？
8. 如果明天遇到同类情况，你会用现有方法、A、B，还是都不用？是什么实际条件决定？
9. 若未来单独征求授权进行一期试点，需要哪些人和哪些条件？现在不请求任何文件或权限。

## 记录重点

匿名编号、最近实例日期（可只记月份）、频次、准备/解释/复核时间及是否估计、现有替代方案、身份字段来源、明确反例、付款决策链、原话与访谈者推断分栏。采用 record-template.md；不得预填成功、需求或付费。
