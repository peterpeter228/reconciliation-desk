# 访谈 05：使用其他流程或连接式工具的人员

状态：PREPARED_NOT_RUN。角色假设：反例样本；允许不使用 ST 或没有近期痛点。无名单、未联系。

## 问题单（先问真实过去行为）

1. 你现在怎样完成收款到银行的核对？最近一次困难是什么，或为什么没有困难？
2. 现有工具已解决哪些步骤？仍需人工的部分有哪些？
3. 如果完全不连接账户、只交付本地证据包，对你是优势还是额外负担？为什么？
4. 什么条件下你绝对不会尝试这个方案？有什么我们假设的问题根本不存在？
5. 看完演示后，哪一段比你当前做法更差？如果不想买，最主要原因是什么？

## 演示之后才问

6. 请用自己的话解释三条证据边。哪一项结论你仍不会信？
7. 你会保留哪个交付物，丢掉哪个？为什么？
8. 如果明天遇到同类情况，你会用现有方法、A、B，还是都不用？是什么实际条件决定？
9. 若未来单独征求授权进行一期试点，需要哪些人和哪些条件？现在不请求任何文件或权限。

## 记录重点

匿名编号、最近实例日期（可只记月份）、频次、准备/解释/复核时间及是否估计、现有替代方案、身份字段来源、明确反例、付款决策链、原话与访谈者推断分栏。采用 record-template.md；不得预填成功、需求或付费。
