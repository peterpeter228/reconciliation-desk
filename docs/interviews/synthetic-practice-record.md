# SYNTHETIC 练习记录：不计入五次访谈

虚构编号：PRACTICE-ONLY。无真人、无真实访谈、无实际报价接受、无计时。以下为训练记笔记的虚构反馈，不构成商业证据。

假设对话：“上个月处理过一次，但不记得准备花多久。通常直接查存款详情。你这个补列可能比我现在做的更慢。”

正确记录：H1 暂有虚构故事但不能计入任何实际统计；时间未知；H2 无法判断；H3 对补列有反例；H4 未询问且未付费；H5 NOT RUN。
错误记录示例（禁止采用）：用户每月有需求、节省两小时、愿付 $199、已经有第一个客户。

练习观察目标：把原话、推断、未知分开；优先追问“上次你如何找到对象关系”，而不是“是不是工具能帮你省两小时”。真实问题访谈必须另行授权联系，不能把这份演练改日期充当记录。
